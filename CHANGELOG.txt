Display Control+ Changelog
=========================

v1.1.2 (2026-11-13)
- Protection no longer stops because metered credits ran out or the license server cannot be reached. Trial, annual, and lifetime entitlements stay local, and a subscription that was synced successfully keeps working for 14 days after the stored period end while the server is unavailable
- Existing v1.0 license files are migrated instead of being quarantined as tampered. A signature mismatch caused by the old signing key or a changing machine fingerprint no longer expires the trial or writes license.json.tampered
- Activity detection captures monitors that sit left of or above the primary display. Those negative virtual-desktop coordinates used to fail inside Pillow with "screen grab failed"
- Login startup is a per-user Run key, so it no longer depends on an elevated scheduled task. Access denied from schtasks is logged and does not block startup
- Background protection logs a real entitlement reason once instead of repeating "waiting for license credits"
- Startup, config, and lock failures in the dashboard log the underlying error instead of a bare catch-all
- Pillow is pinned to 12.3.0 (the open security update). Video mode depends on opencv-python-headless, and the tray and checkout builds exclude OpenCV so those copies are not packed into the installer
- Installer size is still dominated by shipping DisplayControl.exe and overlay_bg.exe as separate one-file builds that each contain OpenCV. A shared one-folder build would remove that second copy; it is not in this release because it changes the install layout

v1.1.1 (2026-05-27)
- Fixed a wake-detection bug that could immediately close newly started overlays before the short timeout behavior was visible
- Restored reliable mixed-timeout behavior so a fast center-display profile can coexist with longer side-display profiles

v1.1.0 (2026-05-27)
- Replaced metered hour-pack billing with a commercial model built around a free trial, annual subscription, and lifetime license
- Added a hosted licensing server flow for checkout confirmation, recovery-based account restore, entitlement sync, subscription state updates, and billing portal access
- Updated the dashboard licensing UI to show account-style entitlements instead of usage-credit packs
- Preserved legacy local credit balances for existing installs while stopping new sales from depending on local hour metering
- Added automated billing tests covering checkout, restore, billing portal, webhook subscription cancellation, local entitlement sync, and localhost client/server round-trips
- Fixed packaged checkout flow by shipping a dedicated checkout helper executable instead of relying on a source-only helper script

v1.0.17 (2026-05-27)
- Fixed monitor selection drift by resolving saved displays using stable device and geometry identity instead of raw enumeration order alone
- Fixed overlay wake behavior so covered displays close on real user input without relying on a second activity-capture pass over blacked-out screens
- Reduced high-frequency input/activity debug logging that could grow the runtime overlay log excessively during long sessions

v1.0.11 (2026-03-23)
- Fixed duplicate tray icons by preventing dashboard startup registration from force-running the tray task
- Added a tray singleton lock so accidental second tray launches exit immediately
- Increased icon fill and sharpening for cleaner rendering on the Windows taskbar and tray

v1.0.10 (2026-03-22)

- Installer now removes legacy shortcut names so updates replace old links cleanly
- Installer triggers an icon cache refresh after install so new shortcut icons appear faster

v1.0.9 (2026-03-22)

- Detection mode selector labels simplified back to Input, Activity, and Both
